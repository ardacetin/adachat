# Ada Chat 1.4.1

> Released 2026-10-06 · [Türkçe özet aşağıda](#türkçe-özet)

A fix release. A review of the whole code base, with the checklists of the
[code review skill](https://github.com/awesome-skills/code-review-skill),
found two serious bugs and a number of smaller ones. All are fixed; most
have a new test. **Every installation should upgrade.**

## Fixes

### Serious

- **Retention clean-up stopped for good on long conversations.**
  - Before: deleting a conversation with more than 15 messages in a thread
    failed, because MySQL refuses deletes that cascade more than 15 levels
    deep. The nightly `ada:retention:prune` then failed every night. No
    deleted or expired conversation was purged after that, nor unsent
    attachments or old usage data.
  - Now: messages are deleted with their conversation, not through the
    thread. A migration changes the database for this.
- **Files of a deleted conversation could still be downloaded** by their
  owner, from an old link, until retention removed them. They now answer
  "not found" as soon as the conversation is deleted.

### Budget and charging

- An answer saved as finished whose charge then failed (a database error,
  or the process stopped between the two) was not charged. The cleanup job
  now charges it.
- When an answer the cleanup job had already estimated finished later,
  input the provider reported as cache reads was charged a second time.
  Only the cost above the estimate is added now.
- An answer stopped or cut off after web searches did not pay for the
  searches, and one whose connection dropped before the provider's last
  event was charged only the usage reported at the start.
- OpenAI reasoning models do not stream their reasoning and report usage
  only at the end. Stopped before that, they were charged no reasoning;
  they are now charged up to the message's output limit, which is what the
  provider may have billed.
- A reservation is freed at once if saving the message fails, instead of
  holding budget for several minutes.

### Administration and e-mail

- **Changing a provider's base URL now requires entering the API key
  again**, so a stored key (or the one in `.env`) is never sent to another
  address.
- Administrators can no longer change their own group or individual
  budget; super administrators still can.
- Cap and user budget alerts that could not be sent (SMTP down, for
  example) were marked as sent and never repeated. They are now tried again
  on the next run.

### Files

- PDF text extraction is limited to 32 MB per decoded stream, so a small,
  highly compressed PDF can no longer exhaust the server's memory.
  Documents over the size limit are refused before they are read.
- Office files with XML parts that are not UTF-8 are refused.

### Chat

- Leaving a conversation while an answer streams no longer brings you back
  to it.
- Stop pressed in the first second (before the answer starts) cancels it as
  soon as it starts; if it never starts, the text and files come back.
- Sending again while the previous answer is being saved no longer makes
  the new message disappear.
- A streaming answer no longer redraws all of its content on every update,
  so its text can be selected while it streams.
- On a Mac only ⌘K opens search; ⌃K edits text again.
- Code highlighting recovers after a failed load.

### Smaller fixes

- Pinned conversations beyond the first 20 show in the sidebar.
- Users with a limit of 0 are no longer counted as having used up their
  budget on the dashboard and in the monthly report.
- Faster search, user page, budget alerts and orphan-file clean-up.
- The SAML sign-in cookie also works when Ada runs under a sub-path.
- The Content Security Policy stays on in production even if a stray
  `public/hot` file is deployed.
- Private files are never served through signed storage URLs.
- Removing the invitation of a disabled account that had tried to sign in
  no longer ends in an error.

Details: [CHANGELOG](https://github.com/ardacetin/adachat/blob/main/CHANGELOG.md#141---2026-10-06).

## Upgrading from 1.4.0

1. Take a backup ([deployment guide §5](https://github.com/ardacetin/adachat/blob/main/docs/deployment.md#5-backups)).
2. Check out the release and follow the usual upgrade steps
   ([guide §8](https://github.com/ardacetin/adachat/blob/main/docs/deployment.md#8-upgrading)):

   ```bash
   git fetch --tags && git checkout v1.4.1
   ```

   With Docker, `docker compose -f compose.production.yml up -d --build`
   rebuilds the image and runs the migrations on start. Without Docker,
   run `npm ci && npm run build`, then `php artisan migrate --force` and
   `php artisan optimize`.
3. Two migrations run. One removes a foreign key from `messages`, the
   other adds an index on stored file paths. Both are quick, but they
   change tables that can be large: run them at a quiet time.
4. If retention clean-up has been failing, the next nightly run catches
   up. To run it at once: `php artisan ada:retention:prune`.
5. Run `php artisan ada:doctor`.

## Known limitations

Unchanged from [1.4.0](https://github.com/ardacetin/adachat/blob/main/docs/releases/v1.4.0.md#known-limitations). In
addition: Gemini's search tool has no per-request limit, so an answer may
search more than its reservation assumed; the excess is charged and
logged.

## Türkçe özet

Ada Chat 1.4.1 bir düzeltme sürümüdür. Tüm kodun incelenmesinde bulunan
iki ciddi ve çok sayıda küçük hata düzeltildi. **Bütün kurulumların
güncellemesi önerilir.**

- **Saklama süresi temizliği uzun sohbetlerde duruyordu.** 15'ten uzun
  bir mesaj zincirine sahip sohbet silinemiyor, gece temizliği her gece
  hata verip hiçbir şeyi silmiyordu. Düzeltildi (bir migration ile).
- **Silinen sohbetin ekleri** eski bağlantıdan indirilebiliyordu; artık
  bulunamıyor.
- **Ücretlendirme:**
  - Kaydedildikten sonra bütçeden düşülemeyen yanıtlar artık
    ücretlendiriliyor.
  - Önbellekten okunan girdi iki kez ücretlendirilmiyor.
  - Durdurulan ya da bağlantısı kopan yanıtların web aramaları
    ücretlendiriliyor.
  - OpenAI'ın akıl yürüten modelleri erken durdurulduğunda, izin verilen
    en fazla çıktıya kadar ücretlendiriliyor.
- **Yönetim:**
  - Sağlayıcının adresi değişince API anahtarı yeniden isteniyor.
  - Yöneticiler kendi grubunu ve bütçesini değiştiremiyor.
  - Gönderilemeyen bütçe uyarıları bir sonraki çalışmada yeniden
    deneniyor.
- **Dosyalar:** PDF okuma bellek sınırıyla yapılıyor; boyut sınırını aşan
  belgeler okunmadan reddediliyor.
- **Sohbet:**
  - Yanıt gelirken başka sohbete geçince geri atılmıyorsunuz.
  - Hemen basılan Durdur metni geri veriyor.
  - Yanıt gelirken metin seçilebiliyor.
  - Mac'te ⌃K yeniden metin düzenliyor.

**1.4.0'dan yükseltme:**

1. Yedek alın, `git checkout v1.4.1` ile güncelleyin
   ([rehber §8](https://github.com/ardacetin/adachat/blob/main/docs/deployment.tr.md#8-güncelleme)).
2. Docker: `docker compose -f compose.production.yml up -d --build`.
   Docker'sız: `npm ci && npm run build`, ardından
   `php artisan migrate --force` ve `php artisan optimize`.
3. İki migration çalışır: `messages` tablosundan bir yabancı anahtar
   kaldırılır ve dosya yollarına indeks eklenir. Büyük tablolarda sakin
   bir saatte çalıştırın.
4. Temizlik bir süredir hata veriyorsa bir sonraki gece kendiliğinden
   telafi eder; hemen çalıştırmak için `php artisan ada:retention:prune`.
5. `php artisan ada:doctor` çalıştırın.
