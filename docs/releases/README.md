# Release notes

One file per release, `vX.Y.Z.md`, with a Turkish summary at the end.

The same text is the body of the GitHub Release, so:

- Links are absolute (`https://github.com/ardacetin/adachat/blob/main/…`).
  Relative links do not resolve on the Release page.
- The GitHub Release takes its title from its own field: paste the file
  from the line after the `# Ada Chat X.Y.Z` heading.
