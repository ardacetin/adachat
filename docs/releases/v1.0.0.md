# Ada Chat 1.0.0

> Released 2026-10-01 · [Türkçe özet aşağıda](#türkçe-özet)

Ada Chat is an open-source, self-hosted AI gateway and chat for universities
and other institutions. People sign in with their institutional account,
chat with the AI models the institution chooses, and stay within a monthly
budget. Administrators manage providers, models, groups and budgets and see
usage and costs, never conversations.

This is the first stable release. It has been built in eleven milestones,
each with tests, documentation and review
([roadmap](../v1-roadmap.md)).

## Highlights

- **Institutional sign-in.** SAML 2.0 with Google Workspace; no passwords in
  Ada. Allowed domains, automatic or pre-created accounts, roles.
- **Several AI providers, one chat.** OpenAI, Anthropic and Google Gemini
  behind model aliases such as "Fast" and "Advanced"; streamed answers, stop,
  regenerate, Markdown and code highlighting, English and Turkish.
- **Budgets that hold.** Every request reserves its maximum cost before it
  is sent and is settled with the real usage afterwards, under database
  locks: a monthly budget cannot be overspent, not even by parallel
  requests. Exact decimal prices, an append-only usage ledger, nightly
  reconciliation.
- **Privacy by design.** Administrators see who used how much, never what
  was asked. A usage notice before first use, retention periods for
  conversations and usage records, API keys encrypted and never logged.
- **Administration.** Dashboard, reports, users, groups, budget policies,
  providers, models, branding and an audit log of every change.
- **Ready to deploy.** A production Docker image and compose file, or a
  step-by-step Ubuntu 24.04 guide, in English and Turkish, with sizing,
  backups, upgrades and a rollout checklist.

The full list is in the [changelog](../../CHANGELOG.md#100---2026-10-01).

## Requirements

| | |
|---|---|
| PHP | 8.4 with `intl`, `mbstring`, `pdo_mysql`, `bcmath`, `zip` (and `redis` with Redis) |
| Database | MySQL 8.4 LTS (the only supported database) |
| Cache and sessions | Redis (recommended) or the database |
| Web server | nginx (configuration provided) |
| Build | Node.js 22 (front-end only) |
| Sign-in | Google Workspace with a custom SAML app |
| AI | An API key for OpenAI, Anthropic or Google Gemini |

Or Docker Engine 24+ with Compose instead of the first four rows.

## Installing

Follow the deployment guide: [English](../deployment.md) ·
[Türkçe](../deployment.tr.md). In short, with Docker:

```bash
git clone https://github.com/ardacetin/adachat.git && cd adachat
git checkout v1.0.0
cp deploy/env.production.example .env        # fill in the values marked CHANGE
docker compose -f compose.production.yml up -d --build
docker compose -f compose.production.yml exec app php artisan ada:install
docker compose -f compose.production.yml exec app php artisan ada:user:promote you@example.edu --role=super_admin
```

Then add a provider and its API key, a model and an alias for the Default
group in the admin panel, and run `php artisan ada:doctor`.

## Upgrading from a pre-release checkout

Installations that followed `main` before this release:

1. Take a backup (deployment guide §5).
2. `git fetch --tags && git checkout v1.0.0`, then the usual upgrade steps
   (guide §8): `composer install --no-dev`, `npm ci && npm run build`,
   `php artisan migrate --force`, `php artisan optimize`, reload PHP-FPM.
3. Review your `.env` against `deploy/env.production.example`. Settings
   added late in development: `LOG_CHANNEL=json`, `TRUSTED_PROXIES`,
   `SESSION_MAX_LIFETIME`.
4. nginx: add `fastcgi_buffer_size 32k; fastcgi_buffers 16 16k;` to the PHP
   location if it is not there; without it some pages answer 502.
5. `php artisan ada:doctor`.

## Known limitations

- One institution per installation; sign-in only through Google Workspace
  SAML (other identity providers are planned).
- Text chat only: no file uploads, images, web search, tools or agents.
- No public API yet (an OpenAI-compatible API is planned).
- Conversation content is stored unencrypted in the database: anyone with
  database or backup access can read it. Protect them accordingly
  ([security.md](../security.md) §9).
- No CSV export or scheduled reports.

## Türkçe özet

Ada Chat, üniversiteler ve kurumlar için açık kaynaklı, kendi sunucunuzda
çalışan bir yapay zekâ geçidi ve sohbet uygulamasıdır. Bu ilk kararlı
sürümdür.

- **Kurumsal giriş:** Google Workspace ile SAML 2.0; Ada'da parola yoktur.
- **Birden çok sağlayıcı, tek sohbet:** OpenAI, Anthropic ve Google Gemini,
  "Hızlı", "Gelişmiş" gibi takma adlarla; akan yanıtlar, durdurma, yeniden
  üretme, Türkçe ve İngilizce arayüz.
- **Aşılamayan bütçeler:** Her istek göndermeden önce en yüksek maliyetini
  ayırır, sonra gerçek kullanımla kapatılır; aylık bütçe paralel isteklerle
  bile aşılamaz.
- **Gizlilik:** Yöneticiler kimin ne kadar kullandığını görür, ne
  sorulduğunu asla görmez. İlk kullanımdan önce kullanım bildirimi, saklama
  süreleri, şifreli ve loglanmayan API anahtarları.
- **Yönetim:** Genel bakış, raporlar, kullanıcılar, gruplar, bütçe
  politikaları, sağlayıcılar, modeller, kurumsal görünüm ve denetim kaydı.
- **Kuruluma hazır:** Docker imajı veya Ubuntu 24.04 için adım adım rehber:
  [deployment.tr.md](../deployment.tr.md).

**Önceden `main` dalını kullanan kurulumlar** için: yedek alın,
`git checkout v1.0.0` ile güncelleyin (rehber §8), `.env` dosyanızı
`deploy/env.production.example` ile karşılaştırın (`LOG_CHANNEL=json`,
`TRUSTED_PROXIES`, `SESSION_MAX_LIFETIME`), nginx'e
`fastcgi_buffer_size 32k; fastcgi_buffers 16 16k;` ekleyin ve
`php artisan ada:doctor` çalıştırın.

**Bilinen sınırlamalar:** kurulum başına tek kurum, yalnızca Google
Workspace SAML ile giriş, yalnızca metin sohbeti (dosya, görsel, web araması
yok), henüz dış API yok, sohbet içerikleri veritabanında şifresiz durur
(veritabanı ve yedekleri buna göre koruyun).
