# Ada Chat 1.5.0

> Released 2026-10-07 · [Türkçe özet aşağıda](#türkçe-özet)

A release that closes gaps: web search with Gemini, answers that no longer
stop during long Anthropic searches, Azure OpenAI as a provider, a
language switch for visitors, and stricter roles between administrators.

## Highlights

- **Web search with Gemini.** Gemini models can now search with Google
  (Grounding with Google Search).
  - Google's terms require its Search Suggestions with every grounded
    answer. Ada shows them, unmodified, under the answer, in a sandboxed
    frame that cannot run scripts or reach Ada; their links open Google in
    a new tab.
  - Google allows grounded answers to be shown only to the person who
    asked: shared links and their copies leave them out and say why.
  - The price catalog lists the Gemini 3.x models with web search at
    Google's list price, $14 per 1,000 searches. Google's monthly free
    searches are not taken into account, so spending is never
    under-counted.
  - Google allows grounded answers to be kept for at most two years:
    `ada:doctor` warns while conversation retention is unset or longer.
- **Long Anthropic searches finish.** When Anthropic paused an answer
  during its web searches, it ended with "The answer reached its length
  limit." Ada now continues it, at most twice, within the same time limit
  and output limit. Each request is charged.
- **Azure OpenAI.** A new provider type for the institution's own Azure
  OpenAI or Foundry resource (v1 API): prompts and answers stay in the
  institution's Azure tenant and region.
  - Address `https://<resource>.openai.azure.com/openai/v1` and the
    resource key; models use the deployment name.
  - Prices are entered in the Advanced model form (they depend on the
    deployment type and agreement). Input is estimated before each
    request, PDFs are sent as text, and web search is not offered.
  - Microsoft Entra ID tokens are not supported yet.
- **Language switch for visitors.** The landing and sign-in pages have a
  language switch. A visitor's choice is remembered in their browser and
  wins over the institution's default language; signed-in users' choice is
  saved as their preference, as in Settings → Language.
- **Administrators and administrators.** Administrators now manage only
  users with the `user` role: another administrator's status, group,
  budget and invitation, and groups with an administrator in them, are
  changed by super administrators.

## Behaviour changes

- If the default group has an administrator in it, only super
  administrators can change it. Put administrators in their own group if
  administrators should keep managing the default group.
- Answers continued after an Anthropic pause read the earlier search
  results again as input; that input can go beyond the reservation, like
  any overshoot, and is charged and logged.

## Maintenance

- CI also fails on moderate npm advisories. Two advisories in build and
  development tools are fixed (`postcss-selector-parser`, and
  `shell-quote`, rated critical); neither is part of the built
  application.
- For contributors using Claude Code on the web, a SessionStart hook sets
  up MySQL and the dependencies.

Details: [CHANGELOG](https://github.com/ardacetin/adachat/blob/main/CHANGELOG.md#150---2026-10-07).

## Upgrading from 1.4.2

1. Take a backup ([deployment guide §5](https://github.com/ardacetin/adachat/blob/main/docs/deployment.md#5-backups)).
2. Check out the release and follow the usual upgrade steps
   ([guide §8](https://github.com/ardacetin/adachat/blob/main/docs/deployment.md#8-upgrading)):

   ```bash
   git fetch --tags && git checkout v1.5.0
   ```

   With Docker, `docker compose -f compose.production.yml up -d --build`.
   Without Docker, run `npm ci && npm run build`, then
   `php artisan migrate --force` and `php artisan optimize`.
3. One migration runs: it adds the Azure OpenAI provider type (a quick
   change to the `providers` table).
4. To use Gemini web search:
   - Admin → Models: turn web search on for the Gemini model, with the
     search price ($14 per 1,000). A model priced from the catalog that
     shows "Use new prices" gets both from the catalog.
   - Allow it on the alias (Admin → Model aliases).
   - Set conversation retention to 730 days or less (Admin → Privacy).
5. Run `php artisan ada:doctor`.

## Known limitations

Unchanged from [1.4.2](https://github.com/ardacetin/adachat/blob/main/docs/releases/v1.4.2.md#known-limitations), except
that Gemini web search is now available, paused Anthropic searches are
continued, and the landing page has a language switch. In addition:

- Azure OpenAI supports key authentication only.
- The Markdown export of a conversation keeps grounded Gemini answers
  without Google's Search Suggestions.

## Türkçe özet

Ada Chat 1.5.0 eksikleri kapatan bir sürümdür.

- **Gemini ile web araması.** Gemini modelleri artık Google ile arama
  yapabiliyor. Google'ın şartları gereği arama önerileri yanıtın altında,
  değiştirilmeden ve script çalıştıramayan izole bir çerçevede gösteriliyor.
  Bu yanıtlar yalnızca soran kişiye gösterilebildiği için paylaşım
  bağlantılarında ve kopyalarında yer almıyor. Katalogda Gemini 3.x
  modelleri 1.000 arama başına 14 $ ile aramalı geliyor; Google'ın aylık
  ücretsiz aramaları hesaba katılmıyor. Sohbet saklama süresi ayarlı değilse
  ya da iki yıldan uzunsa `ada:doctor` uyarıyor.
- **Uzun Anthropic aramaları tamamlanıyor.** Anthropic'in aramalar
  sırasında duraklattığı yanıtlar artık "uzunluk sınırına ulaşıldı" diye
  bitmiyor; en fazla iki kez, aynı süre ve çıktı sınırı içinde devam
  ettiriliyor. Her istek ücretlendiriliyor.
- **Azure OpenAI.** Kurumun kendi Azure OpenAI / Foundry kaynağı için yeni
  sağlayıcı türü (v1 API). Veriler kurumun Azure kiracısında ve bölgesinde
  kalır. Adres ve kaynak anahtarı girilir, modellerde dağıtım adı
  kullanılır, fiyatlar Gelişmiş formdan girilir. Entra ID token'ları henüz
  desteklenmiyor.
- **Ziyaretçiler için dil seçimi.** Karşılama ve giriş sayfasında dil
  seçimi var; seçim tarayıcıda hatırlanıyor.
- **Yöneticiler arası yetki.** Yöneticiler artık yalnızca `user` rolündeki
  kullanıcıları yönetiyor; başka yöneticilerin durumunu, grubunu, bütçesini
  ve içinde yönetici olan grupları süper yönetici değiştiriyor. Varsayılan
  grupta yönetici varsa o grubu yalnızca süper yönetici değiştirebilir.

**1.4.2'den yükseltme:** Yedek alın, `git checkout v1.5.0` ile güncelleyin
([rehber §8](https://github.com/ardacetin/adachat/blob/main/docs/deployment.tr.md#8-güncelleme)).
Bir migration çalışır (Azure OpenAI sağlayıcı türü). Gemini araması için:
modelde web aramasını arama fiyatıyla (1.000 arama başına 14 $) açın,
takma adda izin verin ve sohbet saklama süresini 730 gün ya da daha kısa
yapın. Ardından `php artisan ada:doctor` çalıştırın.
