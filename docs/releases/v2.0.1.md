# Ada Chat 2.0.1

> Released 2026-10-12 · [Türkçe özet aşağıda](#türkçe-özet)

A maintenance release. It catches upgrades that were left half done, signs
in with one click from links when there is a single identity provider, and
updates dependencies. Nothing changes for installations that are already
up to date.

## Highlights

- **Half-finished upgrades are reported.** After 2.0.0, a server that had
  the new code but an old front end build sent the landing page's
  **Sign in** button back to the same page. `php artisan ada:doctor` now
  reports, under *Installation* and *Database*:
  - a front end built from another version: the build writes a hash of its
    sources to `public/build/ada-source.json`, and the doctor compares it
    with the code on the server;
  - PHP packages that differ from `composer.lock`;
  - migrations that have not run.

  Migrations that have not run are always a failure; the other two are
  failures in production and warnings elsewhere.
- **`php artisan ada:upgrade`** finishes an upgrade without Docker. It
  first checks the PHP packages and the front end build and stops with
  instructions if either is out of date; then it migrates in maintenance
  mode, refreshes the caches and runs the doctor. `--no-maintenance` skips
  maintenance mode.

## Behaviour changes

- **`/login` with a single identity provider** goes straight to it, so a
  link to Ada or an expired session signs in with one click. After a
  refused sign-in, with several providers or with the development login it
  still leads to the landing page, which shows the reason or the choices.

## Maintenance

- Dependencies: Laravel 13.35, Inertia 3.9 (inertia-laravel 3.5), Vite+
  1.1, Playwright 1.64 and minor updates of the Radix UI, i18next and
  lucide packages.
- CI runs on `ubuntu-24.04` instead of `ubuntu-latest`, so a new runner
  image no longer changes the test environment unannounced.

Details: [CHANGELOG](https://github.com/ardacetin/adachat/blob/main/CHANGELOG.md#201---2026-10-12).

## Upgrading from 2.0.0

1. Take a backup ([deployment guide §5](https://github.com/ardacetin/adachat/blob/main/docs/deployment.md#5-backups)).
2. Check out the release:

   ```bash
   git fetch --tags && git checkout v2.0.1
   ```

3. With Docker, `docker compose -f compose.production.yml up -d --build`.
   Without Docker ([guide §8](https://github.com/ardacetin/adachat/blob/main/docs/deployment.md#8-upgrading)):

   ```bash
   composer install --no-dev --optimize-autoloader
   npm ci && npm run build
   php artisan ada:upgrade
   sudo systemctl reload php8.4-fpm
   ```

   Always rebuild the front end: the build stamp is new in this version,
   so the doctor reports a missing build until `npm run build` has run.
4. There are no new migrations or settings.

## Türkçe özet

Ada Chat 2.0.1 bir bakım sürümüdür. Yarım kalan güncellemeleri yakalar, tek
kimlik sağlayıcısı olan kurumlarda bağlantılardan tek tıkla giriş yapılmasını
sağlar ve bağımlılıkları günceller.

- **Yarım kalan güncellemeler bildirilir.** 2.0.0'dan sonra kodu yeni ama
  ön yüz derlemesi eski kalan bir sunucuda **Giriş yap** düğmesi aynı
  sayfaya dönüyordu. `php artisan ada:doctor` artık başka bir sürümden
  derlenmiş ön yüzü, `composer.lock` ile uyuşmayan PHP paketlerini ve
  çalışmamış migration'ları bildirir.
- **`php artisan ada:upgrade`** Docker'sız güncellemeyi tamamlar: önce
  paketleri ve ön yüz derlemesini kontrol eder, biri eskiyse ne yapılacağını
  yazıp durur; sonra bakım modunda migration'ları çalıştırır, önbellekleri
  yeniler ve doctor'ı çalıştırır.
- **Tek kimlik sağlayıcısında `/login`** doğrudan sağlayıcıya gider; Ada'ya
  bir bağlantı ya da süresi dolan oturum tek tıkla giriş yapar. Reddedilen
  girişten sonra, birden fazla sağlayıcıda veya geliştirme girişinde
  karşılama sayfası açılır.
- **Bakım:** Laravel 13.35, Inertia 3.9, Vite+ 1.1, Playwright 1.64 ve küçük
  güncellemeler; CI `ubuntu-24.04` üzerinde çalışır.

**2.0.0'dan yükseltme:** Yedek alın, `git checkout v2.0.1` ile güncelleyin.
Docker ile `docker compose -f compose.production.yml up -d --build`. Docker'sız
([rehber §8](https://github.com/ardacetin/adachat/blob/main/docs/deployment.tr.md#8-güncelleme)):
`composer install --no-dev --optimize-autoloader`, `npm ci && npm run build`,
`php artisan ada:upgrade`, ardından PHP-FPM'i yeniden yükleyin. Ön yüzü her
zaman yeniden derleyin. Yeni migration veya ayar yoktur.
